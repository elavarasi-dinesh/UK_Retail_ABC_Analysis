# UK_Retail_ABC_Analysis

# UK Retail Inventory Prioritisation Using Python ABC Analysis

## Project Overview
This project uses ABC Analysis to prioritise retail inventory based on annual sales revenue. It demonstrates how Python can help retailers identify high-value products and make data-informed inventory decisions.

## Business Problem
Retailers manage products with different levels of sales contribution. Treating every product equally can lead to inefficient stock management and missed opportunities.

## Objectives
- Calculate annual revenue for each product.
- Rank products by revenue contribution.
- Calculate cumulative revenue percentages.
- Classify products into A, B and C categories.
- Develop practical inventory management recommendations.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

## Methodology
1. Load and inspect the dataset.
2. Clean and validate the data.
3. Calculate annual revenue.
4. Sort products by revenue in descending order.
5. Calculate cumulative revenue contribution.
6. Assign ABC classifications.
7. Visualise the results and interpret business implications.
